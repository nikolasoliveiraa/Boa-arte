# Boa Arte

Site estatico em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html`: pagina inicial
- `pages/`: paginas das colecoes
- `css/style.css`: estilos do site
- `js/script.js`: comportamento e galeria
- `assets/images/`: imagens e capa

## Execucao

Abra `index.html` no navegador ou publique a raiz do projeto na Vercel. Nao ha etapa de build nem dependencias de npm.

## Rotas principais

- `/`
- `/pages/abstrato.html`
- `/pages/jesus.html`
- `/pages/minimalista.html`
